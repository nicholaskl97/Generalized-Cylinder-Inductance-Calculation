This repository contains a Julia function, `generalized_cylinder_inductance`, for calculating the inductance of a generalized cylinder[^1], and another function `generalized_cylinder_inductance_per_length` for calculating the marginal inductance contribution of each vertical strip in such an inductor.
It additionally contains a function, `circular_cylinder_inductance`, for calculating the inductance of a circular cylinder using Nagaoka's coefficient, and a short example that uses both and confirms their agreement.

[^1]: N. Klugman, J. Vedral and J. Lang, "Self-Inductance of an Extrusion of a Planar Curve," 2020 International Applied Computational Electromagnetics Society Symposium (ACES), Monterey, CA, USA, 2020, doi: [10.23919/ACES49320.2020.9196194](https://doi.org/10.23919/ACES49320.2020.9196194).
